# Hash4

Hash4 is a full-stack real estate platform focused on properties across Tamil Nadu, India, with its primary operations based in Chennai.

## Project Goal

The goal of Hash4 is to build a production-style full-stack application while learning and applying modern software engineering technologies.

## Planned Technology Stack

### Frontend
- React
- TypeScript

### Backend
- Python
- FastAPI

### Database
- PostgreSQL

### Caching
- Redis

### DevOps
- Docker
- GitHub Actions

### AI
- Natural-language property search
- LLM integration

## Core Features

- Browse properties
- Search and filter properties
- View property details
- Save favorite properties
- Schedule site visits
- Contact agents
- Agent/admin dashboard
- Property management
- Lead management
- AI-powered property search

## Primary Market

Chennai, Tamil Nadu, India
